Build a complete, modern, premium and highly attractive WEBSITE FOR A GAMING CAFE.

The website must feel UNIQUE and professionally designed, not like a generic AI-generated gaming website.

The design should combine:
- Premium gaming lounge
- Modern esports atmosphere
- Classic/elegant visual design
- Strong UX
- Smooth but controlled animations
- High visual hierarchy
- Real business usability

IMPORTANT:
Do NOT create a typical "cyberpunk neon everywhere" website.
Do NOT overuse gradients, glowing borders, glassmorphism, huge shadows, or random animations.
Do NOT make every section look like a game HUD.
The website should feel premium, polished, memorable and believable as a real gaming cafe.

27. RESPONSIVE DESIGN
==================================================

Build mobile-first.

Desktop must look premium.

Tablet must remain balanced.

Mobile must NOT simply be a shrunk desktop version.

On mobile:
- Stack sections intelligently
- Use horizontal scrolling where appropriate
- Keep buttons easy to tap
- Simplify complex tables
- Convert pricing tables into responsive cards when needed
- Keep important CTAs accessible
- Use a sticky BOOK NOW CTA when useful
- Keep navigation simple

Test at:
- 320px
- 375px
- 390px
- 430px
- 768px
- 1024px
- 1440px
- 1920px
